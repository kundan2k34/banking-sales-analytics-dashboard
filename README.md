# Banking Sales Analytics Dashboard

## 📌 Project Overview
The Banking Sales Analytics Dashboard is an end-to-end data analytics project developed to analyze banking sales performance, customer engagement, loans, deposits, and financial insights using multiple analytics tools.

This project combines SQL, Python, Excel, and Power BI to transform raw banking data into meaningful business insights and interactive dashboards.

The dashboard helps in:
- Monitoring banking performance
- Analyzing customer and loan data
- Tracking deposits and financial goals
- Visualizing sales and engagement trends

---

## 🚀 Technologies Used

- SQL – Data extraction and querying
- Python – Data cleaning and preprocessing
- Excel – Initial data handling and analysis
- Power BI – Interactive dashboard and visualization

---

## 📊 Dashboard Features

### 🔹 Loan Analysis
- Total Loan Analysis
- Loan Distribution by Income Band
- Loan Analysis by Nationality

### 🔹 Deposit Analysis
- Total Deposits
- Savings and Checking Amount Analysis
- Foreign Currency Amount Analysis

### 🔹 Customer Insights
- Total Clients
- Engagement Accounts
- Credit Card Accounts

### 🔹 Financial KPI Tracking
- Total Fees
- Business Lending
- Financial Goals Comparison

---

## 📈 Key Insights

- Bank loans are highest for the Mid Income Band
- European countries have the highest banking features
- Australian countries show the lowest loan distribution
- Deposit and lending trends help understand customer financial behavior
